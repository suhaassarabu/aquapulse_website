## 🚀 Getting Started Locally

To get a local copy up and running, follow these simple steps.

### Prerequisites
Make sure you have Git installed.

### Installation

1. Clone the repo
   ```sh
   git clone [https://github.com/suhaassarabu/aquapulse_website.git](https://github.com/suhaassarabu/aquapulse_website.git)
   ```
2. Navigate into the project directory
   ```sh
   cd aquapulse_website
   ```
3. Open the `index.html` file in your browser, or if using a framework, install NPM packages:
   ```sh
   npm install
   npm run dev
   ```
